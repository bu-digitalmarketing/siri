# เว็บไซต์โปรไฟล์ส่วนตัว

เว็บหน้าเดียว (single page) ไม่ต้องติดตั้งอะไรเพิ่ม — เปิดไฟล์ `index.html` ได้เลย

## วิธีแก้ข้อมูล

แก้ไฟล์ **`data.js`** ไฟล์เดียวพอ — ชื่อ, ตำแหน่ง, เกี่ยวกับฉัน, ทักษะ,
ประสบการณ์, ผลงาน และช่องทางติดต่อ อยู่ในนั้นทั้งหมด
ช่องทางติดต่อช่องไหนที่เว้นว่าง (`""`) ไว้ จะไม่แสดงบนเว็บ

## รูปโปรไฟล์

1. วางไฟล์รูปไว้ในโฟลเดอร์ `assets/` เช่น `assets/profile.jpg`
2. แก้ใน `data.js` → `photo: "assets/profile.jpg"`

ถ้าไม่ใส่รูป เว็บจะแสดงเป็นตัวอักษรย่อของชื่อแทน

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `data.js` | **ข้อมูลส่วนตัวทั้งหมด — แก้ที่นี่** |
| `script.js` | นำข้อมูลจาก data.js มาแสดงผล + ธีม/เมนู/แอนิเมชัน |
| `styles.css` | สไตล์และการจัดวาง |
| `assets/` | รูปภาพ |

## เปิดดูเว็บ

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์ในเครื่อง:

```bash
python3 -m http.server 8000
```

## ฟีเจอร์

- โหมดสว่าง/มืด (จำค่าที่เลือกไว้)
- รองรับมือถือเต็มรูปแบบ
- แอนิเมชันตอนเลื่อนหน้า (ปิดอัตโนมัติถ้าผู้ใช้ตั้งค่า reduced motion)
- เมนูไฮไลต์ตามหัวข้อที่กำลังอ่าน
- รองรับ screen reader และการใช้คีย์บอร์ด
